How to play

From an empty tab to the Mojave Wasteland in a few steps.

1. Check what you need

  • A desktop or laptop with the current Chrome or Edge. The game uses WebGPU; if the page says it is missing, update the browser and your graphics driver, or try another device.
  • Your own installed copy of Fallout: New Vegas. The GOG release (version 1.4.0.525) is the one this is built for.
  • Some patience on the first start: the game's program and your game files have to load, and the page shows an estimate before it begins.

2. Link your game

  1. On the game page, press Choose installation folder.
  2. Pick the folder that contains FalloutNV.exe and the Data folder. The browser asks permission to read it. The files are read in your browser.
  3. Press Choose and remember folder instead if you want the browser to keep the link for next time.
  4. Use Change installation to link a different copy.

3. Start

Choose Start normally for the game's usual beginning, or Start in the wasteland to skip ahead into the world. Click the game once to give it the mouse and keyboard.

4. Controls

The keyboard and mouse controls are the game's own, as set in its options. By default: W A S D to move, the mouse to look, left click to fire, right click to aim, Tab for the Pip-Boy, V for V.A.T.S., E to use, R to reload, Ctrl to sneak, Space to jump and Esc for the menu. On a phone or tablet an on-screen joystick and buttons appear, and swiping looks around. The Fullscreen button gives the game the whole screen.

5. Saving

The game's own saves work as usual. Under the game, Save game makes a quicksave and downloads it as a .fos file to your disk, and Load game loads a .fos file you pick. Keep the downloaded files: saves kept in the browser can be lost if you clear its data.

6. Performance

  • Leave Auto quality on. It shortens the view distance when the frame rate falls below 60 and restores it when there is time to spare.
  • Close other heavy tabs and programs, and use a computer with a dedicated graphics card if you can.
  • Plug a laptop in; battery saver modes slow the graphics.

7. If something goes wrong

  • WebGPU not available. Update the browser and graphics driver, and make sure hardware acceleration is on in the browser's settings.
  • The folder is refused or not recognised. Pick the folder that holds FalloutNV.exe and Data side by side.
  • It crashed or looks wrong. Press Report a problem under the game and describe what happened. The log is sent with the report; the privacy policy lists what it contains.

Talk to other players

The Chat tab above the game opens a public room where players can talk. It can translate messages into your language. Be kind: messages that break the terms are removed.
