Credits

Fallout: New Vegas in the browser, recompiled from your own copy of the game. It stands on other people's work.

fnv_decomp: the foundation

fnv_decomp, the community decompilation coordinated on fnvdecomp.com, rebuilt the game's program as C++, function by function, each one checked to compile to the same bytes as the original. Its names, types and layouts are how every part of this port understands the game.

Its authors released it with no licence and said that credit is not required. We credit them anyway, because this port would not exist without them. The largest contributions came from connorx2000, h-x3n, L1ll3J, andgju, gavinbrow, FFwLo, MK5280, momentom861, MatiasIsGood and Stargallian, with 35 more named contributors and 8 who took part anonymously. The full list is in their credits.

nv-rs: design ideas

nv-rs, by slaterain and its contributors, is a new engine for the game written in Rust. We took two ideas from it: running the game's threads as deterministic coroutines, and modelling Direct3D 9 as a complete state machine. No nv-rs code was copied.

Tools

  • LLVM/Clang and Emscripten build the game for the browser.
  • Capstone disassembles the program for the recompiler.
  • vkd3d and Tint translate the game's shaders to WebGPU.
