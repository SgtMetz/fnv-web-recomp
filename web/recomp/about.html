About New Vegas Recompiled

Fallout: New Vegas in a web browser, from your own copy of the game.

What it is

New Vegas Recompiled is a fan engineering project. It takes the program of the 2010 role-playing game Fallout: New Vegas (FalloutNV.exe, the GOG release, version 1.4.0.525) and translates it ahead of time into WebAssembly, the code format web browsers run. The game's graphics calls, which were written for Direct3D 9, are translated to WebGPU, and its sound, input and file access are connected to browser features. The result runs in a tab, with no installation.

It needs your own copy of the game

This site contains no game content: no maps, models, textures, sounds, scripts or quests. To play you pick the folder of your own installed copy (the one that holds FalloutNV.exe and Data), and the browser reads the files straight from that folder on your computer. Without a legitimate copy of the game there is nothing to play. How to play walks through the steps.

How it works, briefly

  • Recompilation. A tool reads the machine code of the original program and writes equivalent WebAssembly for every function, so the game's own logic runs as the developers made it. It is not a rewrite or a clone.
  • A community decompilation. The effort builds on fnv_decomp, which gives the game's functions, types and data layouts their names. See the credits.
  • Graphics. The game's Direct3D 9 shaders and draw calls are translated to WebGPU, so a browser with WebGPU and a reasonably modern graphics card is required.
  • Saves. Saves are kept in your browser and can be downloaded to, and loaded from, a file on your disk.
  • Automatic quality. The page watches the frame rate and shortens the view distance when the game runs slowly.

What you need

  • A computer with a recent version of Chrome or Edge, which have WebGPU. Phones and tablets get touch controls, but a desktop is far better.
  • A graphics card that WebGPU supports, and several gigabytes of free memory.
  • Your own installed copy of Fallout: New Vegas.

Status

The project is under active development and not every part of the game is complete. You can start a new game and walk around the Mojave, and the remaining problems are being worked through. If something goes wrong, use the Report a problem button under the game; it sends the game's log so the cause can be found.
