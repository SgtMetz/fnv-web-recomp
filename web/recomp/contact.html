Contact

New Vegas Recompiled is made by Metz.

Report a problem with the game

Press Report a problem under the game. Describe what went wrong; the report carries the game's log so the cause can be found, and you can leave a contact detail if you want a reply. This is the fastest way to be heard.

Bugs, questions and ideas

Open an issue on GitHub, where the project's code lives. You can also message SgtMetz there.

Privacy requests, chat removal and anything else

Use the same two ways: a report with your contact detail, or a GitHub issue. Say what you need (for example "remove my chat message", with the time and your chat name) and we will answer there. Please do not post private information in a public issue; send it through Report a problem instead.
